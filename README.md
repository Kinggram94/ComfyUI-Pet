# Comfyui-Pet（ComfyUI 桌宠）

一只常驻在 ComfyUI 界面上的鲸鱼娘桌宠（Maid DeepSeek Whale，动画素材来自 DSH 开源的 dsh-pet 仓库）。在画布状态栏实时显示 CPU / 内存 / GPU / 显存 / GPU 温度，附带一键内存/显存清理、两个清理节点、一个 Qwen 图像编辑节点和一个 Ultralytics 检测器节点，运行报错时还能自动调用大模型分析原因并给出解决办法。

## 安装

1. 把整个 `ComfyUI-Pet` 文件夹放进 ComfyUI 的 `custom_nodes` 目录
2. 首次安装或更新后重启 ComfyUI，再在浏览器里按 Ctrl+F5 强制刷新
3. 桌宠和清理节点无需额外安装依赖：CPU / 内存读取使用 ComfyUI 自带的 `psutil`；GPU 利用率与温度优先使用环境里已有的 `pynvml`，没有时自动退回 `torch` 只显示显存占用。Ultralytics 检测节点使用环境里已有的 `ultralytics`（两个 ComfyUI 环境均已安装）

卸载：删除该文件夹即可，浏览器端不会留下残留设置（可在设置 → 宠物 里清掉个人配置）。

## 功能总览

### 状态联动
- **待机**：呼吸休闲动画，隔一会儿随机表演一个小动作（下棋、跳舞、吃点心……共 100+ 个）
- **运行中**：头顶气泡实时显示已运行时长、当前执行的节点、进度百分比
- **完成 / 失败**：显示总用时提示，6 秒后自动回到待机
- 状态来自 ComfyUI 执行事件 + `/queue` 轮询双通道，不怕漏报

### 交互
- **左键单击**：下蹲弹跳 + 随机播放一个点击回应动作
- **拖拽**：按住拖到任意位置，有专属拖拽动画，位置自动记忆
- **抛飞**：快速甩出去会抛飞、落地弹跳（可在设置里关闭）
- **双击**：播放完整清理动画，同时调用 ComfyUI 内置 `/free` 清理内存与显存
- **右键**：功能菜单

### 资源监控
- ：放在画布顶部状态栏的描边按钮组内，默认排在翻译开关 / 管理器等已显示插件的左边，不占用原来运行按钮的位置，也不占用宠物气泡
- 五条紧凑的占用条：**CPU / 内存 / GPU / 显存 / GPU 温度**，每 2 秒刷新一次
- GPU 温度优先由 `pynvml` 读取；没有 `pynvml` 时只显示显存，不显示温度
- 总开关：右键菜单里的「资源监控」或 设置 → 宠物 → 资源监控

### 右键菜单（锚定宠物的气泡面板）
- **动作选项**：居中弹窗，搜索 + 一次性列出全部内置动作，单击立刻预览；右键某个动作可把它设为 待命 / 运行中 / 运行完成 / 运行失败 / 双击清理 的专属动画。动作列表分批渲染，打开和搜索不再卡顿
- **报错分析**：居中弹窗，查看最近一次错误的分析结果与原始日志，可重新分析
- **资源监控**：总开关（显示 / 隐藏画布状态栏里的监控条）
- **清理缓存**：
  - ✓ 运行前清理 —— 每次开跑时后台静默清一次内存/显存（无动画、不打扰）
  - ✓ 运行后清理 —— 运行成功结束后自动静默清一次
  - 立即清理一次 —— 打开居中清理窗口，显示清理进度与结果；双击宠物的清理结果仍显示在头顶气泡
- **隐藏宠物**：隐藏后可在 设置 → 宠物 → 显示桌宠 恢复

### 清理节点
在节点菜单 **内存管理** 分类下新增两个中文节点（与原版 `Comfyui-Memory_Cleanup` 可共存）：
- **清理显存**：卸载模型 / 清空显存缓存，可选任意输入透传
- **清理内存**：清理文件缓存 / 进程工作集 / 未使用 DLL，可设置重试次数，可选任意输入透传

### Qwen 图像编辑节点
在节点菜单 **conditioning** 分类下新增 **Easy_QwenEdit2509**（节点名与原插件 `easy_qwenEdit_2509` 完全一致，已有工作流无需改节点）：
- 最多 3 张参考图 + 文本提示，输出 `positive` / `zero_negative` / `latent`
- `latent_image` 决定生成尺寸；参考图尺寸不一致时按 `auto_resize` 统一（crop 中心裁剪 / pad 黑色填充 / stretch 强制拉伸）
- `vl_size` 控制视觉编码尺寸，3 张参考图可分别设置强度，支持系统提示词与生成遮罩
- 取消官方 1024×1024 百万像素限制，任意尺寸直接出图（输出仍会对齐到 8 的倍数）
- 节点代码迁移自 `easy_qwenEdit_2509`（MIT License）

### Ultralytics 检测器节点
在节点菜单 **ImpactPack** 分类下新增 **UltralyticsDetectorProvider**（节点名与原插件 `ComfyUI-Impact-Subpack` 完全一致，已有工作流无需改节点）：
- 输出 `BBOX_DETECTOR` / `SEGM_DETECTOR`，模型下拉框读取 `models/ultralytics/bbox` 与 `models/ultralytics/segm`
- 便携版已放入 `bbox/face_yolov8m.pt`；主环境检测到同级已安装 `ComfyUI-Impact-Subpack` 时自动跳过注册，继续使用原插件，避免同名节点冲突
- 依赖环境里已有的 `ultralytics` 包；检测器代码移植自 `ComfyUI-Impact-Subpack`（AGPL-3.0）

### 报错分析（AI）
- 运行失败时自动抓取错误日志发给大模型，返回「原因 + 解决办法」
- 结论以美化气泡显示在宠物头顶：左键点宠物关闭，60 秒无操作自动消失
- 支持任意 OpenAI 兼容接口；**默认 DeepSeek**（`https://api.deepseek.com` + `deepseek-chat`），可自行换成豆包方舟等其他供应商
- 可选「过滤思维链」：隐藏模型推理过程，只看结论
- **API Key 只存在浏览器的本地存储中**，不写入 ComfyUI 设置页、不随插件文件分发——把本插件分享给别人不包含你的任何密钥

## 设置项（ComfyUI 设置 → 宠物 选项卡）

| 设置 | 说明 |
| --- | --- |
| 大小 | 50%–200%，100% 为原始大小 |
| 抛射 | 甩出后飞行弹跳的开关 |
| 显示桌宠 | 显示 / 隐藏 |
| 资源监控 | 画布状态栏 CPU / 内存 / GPU / 显存 / 温度显示的总开关 |
| 运行前清理 | 开跑时自动清一次内存/显存 |
| 运行后清理 | 成功跑完后自动清一次 |

| 过滤思维链 | 隐藏模型推理过程 |
| 接口地址 / 模型 | OpenAI 兼容接口配置（API Key 在右键 → 报错分析 → 供应商配置 里填，密码框输入） |

## 兼容说明

- 自动隐藏 ComfyUI-Chinese-Translation 顶栏的「翻译开启」开关：通过 CSS 覆盖实现，不修改该插件文件，升级该插件后依然隐藏；翻译功能仍可在它的设置面板里切换。
- 隐藏时保留了 1px 的不可见占位，是为了避开该插件每 2 秒一次的可见性看门狗（若直接 `display:none`，它会被反复移除重插）。
- 自动隐藏 ComfyUI-Manager 顶栏的「收藏 / 释放模型 / 释放模型+节点缓存 / 分享」按钮，同样用 CSS 覆盖、不改管理器文件，升级后依然有效；左侧的「管理器」按钮保留。匹配依据是图标类而不是文字，因此汉化插件翻译按钮提示后仍然生效。

## 素材说明

内置 Maid DeepSeek Whale 全套 webm 动画，默认从 jsDelivr 加载固定版本，失败时自动逐级回退到 GitHub raw 等多个地址；全部加载失败时显示圆形头像兜底，联网恢复后自动切回动画。

```
├── __init__.py              # 注册只读监控路由与全部节点
├── pet_stats.py             # CPU / 内存 / GPU / 显存采集（1 秒缓存）
├── memory_cleanup.py        # 清理显存 / 清理内存节点
├── easy_qwen_edit_2509.py   # Easy_QwenEdit2509 图像编辑节点
├── ultralytics_detector.py  # UltralyticsDetectorProvider 检测器节点（移植自 Impact-Subpack）
├── web/
│   ├── main.js        # 前端逻辑（气泡菜单 / 动作面板 / 资源监控）
│   ├── pet_utils.js   # 纯函数工具（百分比 / 容量 / 气泡定位）
│   └── icon.jpg       # 兜底头像
└── tests/             # JS / Python 单元测试
```
